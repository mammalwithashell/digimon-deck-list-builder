# Rust engine gap-closure plan — TS Olympos

## Goal

Close the 100 blocking and 4 partial engine gaps below so that **TS Olympos** (meta_share 3.40%, 64 decklists, 105 unique cards) can be fully implemented in `digimon-engine/` without stubs, approximations, or auto-selections (per CLAUDE.md §17–18).

The archetype is a blue-heavy, tamer-driven Olympos XII / [TS]-trait archetype whose payoff mechanics layer **tamer-gated memory generation**, **OPT [When Attacking] riders**, **Option cards with `<Delay>` and `Plug-In/Link`**, **`<Barrier>` on the boss line**, and **face-printed `<Raid>` / `<Blocker>` / `<Jamming>` / `<Reboot>` / `<Alliance>` keywords** — none of which the current Rust engine dispatches from printed-text parsing or wires in combat.

Audit summary (`/assess-archetype-rust TS Olympos`, 2026-04-18):

- 105 cards audited (21 batches: 10 Opus × 5, 11 Sonnet × 5)
- 🟢 SUPPORTED: 1 (BT24-028 Divermon — vanilla, no effect text)
- 🟡 PARTIAL: 4 (BT24-002 Bukamon, P-199 Dan Yuki, P-210 Hiroko Sagisaka, BT6-082 Sistermon Blanc)
- 🔴 BLOCKING: 100
- 0 cards already registered in Rust (`digimon-engine/src/cards/` currently holds only `test/` and a `bt17/` stub)
