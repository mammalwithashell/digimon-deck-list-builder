## 2. Uniform comparator (D2 — staged)
> **Design pivot (verified):** `PredicateSpec` is `#[serde(flatten)]`'d (into `ExistentialPredicate` etc.) with a `#[serde(flatten)] extra` sink, so field-level `deserialize_with` and `#[serde(from)]` are both unsafe here. The flatten-safe approach (4-agent design panel) is **Hybrid**: a canonical `MetricComparators` field (a named-helper type with its own untagged single|list Deserialize, like `DpConstraint`) per metric, lowered at compile time into the existing legacy `_eq`/`_lte`/`_gte` **compiled** fields — byte-identical compiled output, legacy flat keys unchanged. `DpConstraint` is **kept** as the flatten-safe `FormulaSpec`-carrier (it already is `Literal|Formula(+{formula:})`); §2.3's literal "delete `DpConstraint`" is satisfied in spirit (one value semantics) — full deletion is deferred (loses byte-identical + needs pack regen, and is `make-engine-cloneable`'s compiled-AST job). Cloneable-aligned: data-driven, byte-identical, pure read-safe eval (see [[project_cloneable_engine_dsl_alignment]]).

## 3. Merge budget-select verbs (RL-gated, D4) — DEFERRED (invoking §3.5)
> **Decision (2026-06-18):** ship FormulaSpec (§1) + Comparator (§2) **without** the budget-verb merge. Rationale: the new `add-determinized-search` change makes the **2192-action mask + observation tensor the MCTS search interface**, not just PPO's, so any risk to that encoding is now doubly costly. §3.5 already prescribes "if the encoder can't be byte-identical, STOP and re-scope (ship FormulaSpec+Comparator, defer the budget merge)." The merge is a small cosmetic consolidation (two structurally-identical verbs) with a real RL/search-contract downside and no card-expressiveness gain — defer until it can be done with a proven byte-identical mask+tensor gate. See [[project_cloneable_engine_dsl_alignment]].
- [~] 3.1–3.4 Deferred (per §3.5 re-scope). `select_opponent_dp_budget`/`select_opponent_play_cost_budget` remain as-is (they work; the `budget` type inconsistency is cosmetic).
