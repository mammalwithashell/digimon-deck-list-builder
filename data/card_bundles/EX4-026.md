## Printed text (official)
### Effect
The name of this card/Digimon is also treated as [Kyubimon]. [On Play] [When Digivolving] Until the end of your opponent's turn, 1 of your Digimon gains ＜Blocker＞. (When an opponent's Digimon attacks, you may suspend this Digimon to force the opponent to attack it instead.)

### Inherited Effect
[Your Turn][Once Per Turn] When you use an Option card with a cost of 2 or more, 1 of your opponent's Digimon gets -2000 DP for the turn.

## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=EX4-026 (via data/card_official_qa.json)_
- **Q3467** (2025-11-21) Q: If the "when you use an Option card" effect triggers, what is the timing when it can activate? — A: It can be activated after activating the used Option card's [Main] effect.
- **Q3468** (2024-08-01) Q: What does this card's (Rule) mean, exactly? (*This card's "The name of this card/Digimon is also treated as [Kyubimon]" has been changed to "(Rule) Name: Also treated as [Kyubimon].") — A: This is a special rule for this card that always treats it as if it also has the [Kyubimon] name.
- **Q5491** (2025-11-21) Q: Does the "when you use an Option card" effect trigger if an Option card's effect activates by a method other than using the card? — A: No, it doesn't trigger. If an Option card's effect activates without using it, such as activation by a [Security] effect or <Delay>, the "when you use an Option card" effect doesn't trigger.
- **Q5492** (2025-11-21) Q: An Option card's use cost is 1 or less when used from the hand due to an effect such as BT2-099 [Glorious Burst] or BT8-097 [Crimson Blaze]'s 1st effect. When such a card is used, does this card's "when you use an Option card with a use cost of 2 or more" effect trigger? — A: No, it doesn't trigger. If a card's cost itself is reduced when it's used from the hand, it's considered to be using an Option card with a use cost after the reduction is applied. Therefore, the "when you use an Option card with a use cost of 2 or more" effect doesn't trigger. _(related: BT2-099, BT8-097)_
- **Q5493** (2025-11-21) Q: An Option card has an original use cost of 2 or more, and I use it when the cost to pay is reduced to 1 or less. At such times, does this card's "when you use an Option card with a use cost of 2 or more" effect trigger? — A: Yes, it triggers. If the card's cost to pay is reduced and not the use cost itself, it's considered to be using an Option card with its original value as its use cost. Therefore, the "when you use an Option card with a use cost of 2 or more" effect triggers.
- **Q5494** (2025-11-21) Q: I used an effect to use an Option card with an original use cost of 2 or more without paying the cost. At such times, does this card's "when you use an Option card with a use cost of 2 or more" effect trigger? — A: Yes, it triggers.
