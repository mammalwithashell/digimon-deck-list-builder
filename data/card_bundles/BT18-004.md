## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT18-004 (via data/card_official_qa.json)_
- **Q2904** (2024-11-22) Q: What happens to cards placed face up in the security stack by effects? — A: They become face-up security cards that remain revealed. Other than rules that specify face-up security cards, the rules apply in the same manner as standard security cards.
- **Q2905** (2024-11-22) Q: What happens upon a security check for a security card that is placed face-up? — A: The check is performed with the card left revealed. Other than rules for cards left revealed, the rules apply in the same manner as standard security checks.
- **Q2906** (2024-11-22) Q: Does a card's [Security] effect trigger upon a security check with that card placed face-up? — A: Yes, it triggers.
- **Q2907** (2024-11-22) Q: What happens if I shuffle a security stack that includes security cards placed face-up? — A: Any face-up cards are placed face down, then you shuffle the cards. After shuffling, all cards are left face-down.
- **Q3146** (2024-09-20) Q: This card's [Start of Your Main Phase] effect and BT18-004 [Puroromon]'s inherited effect triggered simultaneously when I had no face-up security cards. At such times, can I use BT18-004 [Puroromon]'s effect to place a card from my hand face up as my bottom security card, then use this card's effect to gain 1 memory? — A: Yes, you can.
