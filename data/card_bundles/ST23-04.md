## Official Q&A
- No, it isn't deleted yet. Once all of the processing for this card's [On Play] [When Digivolving] effect is resolved, then all of the Digimon with 0 DP are deleted at the same time. In addition, if an Option card is used by this effect, once the used Option card's [Main] effect has resolved and the Option card is trashed, then all Digimon with DPs of 0 will be deleted. If digivolving by Arts Digivolve, after digivolving, all of the Digimon with 0 DP are deleted.
