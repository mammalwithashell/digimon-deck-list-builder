## Printed text (official)
### Effect
Treat this card/Digimon as if it also has [Leomon] in its name. [All Turns] When this Digimon would be deleted in battle, you may play 1 [Leomon] from this Digimon’s digivolution cards without paying its memory cost.

## Official Q&A
- This is a special rule for this card that always treats it as if it also includes the [Leomon] name. This (Rule) allows this card to be chosen for text that specifies cards with [Leomon] in their names. This (Rule) does not allow this card to be chosen for text that specifies cards with the name [Leomon].
