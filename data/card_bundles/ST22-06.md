### Effect
[On Play] [When Digivolving] You may use 1 Option card with the [Onmyōjutsu] or [Plug-In] trait from your hand or under your Tamers without paying the cost. [All Turns] [Once Per Turn] When you use Option cards or your security stack is removed from, by placing 1 of your opponent's Digimon with the lowest DP as the bottom security card, trash their top security card.

## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=ST22-06 (via data/card_official_qa.json)_
- **Q5421** (2025-11-21) Q: If I use this card's [On Play] [When Digivolving] effect to use an Option card from under a Tamer, what happens to that Option card? — A: As with the standard rules, a used Option card is temporarily treated as not being in any area. After using it and activating the Option card's [Main] effect, the card is trashed unless it's to be placed in an area.
- **Q5422** (2025-11-21) Q: If the "when you use an Option card" effect triggers, what is the timing when it can activate? — A: It can be activated after activating the used Option card's [Main] effect.
- **Q5423** (2025-11-21) Q: Does the "when you use an Option card" effect trigger if an Option card's effect activates by a method other than using the card? — A: No, it doesn't trigger. If an Option card's effect activates without using it, such as activation by a [Security] effect or <Delay>, the "when you use an Option card" effect doesn't trigger.
- **Q5424** (2025-11-21) Q: In what order do a [Security] effect, "when [...] performs a security check" effect, and "when a card is removed from [...] security stack" effect activate when they trigger simultaneously upon a security check? — A: [Security] effects take precedence for activation. Upon a security check, a [Security] effect will immediately activate without pending activation. For other triggered effects, the turn player activates their effects first.
- **Q5425** (2025-11-21) Q: I tried to use this card's [All Turns] effect to place an opponent's Digimon as the bottom security card, but another effect prevented that Digimon from leaving. At such times, does this effect trash an opponent's security card? — A: No, it isn't trashed.
- **Q5426** (2025-11-21) Q: I tried to use this card's [All Turns] effect to place an opponent's Digimon as the bottom security card, but another effect prevented that Digimon from leaving. At such times, does it count as a use of this effect's [Once Per Turn]? — A: Yes, it counts. A use of [X Per Turn] occurs as soon as you choose to activate the effect. In this case, a use of [Once Per Turn] occurs as soon as you choose to place an opponent's Digimon as the bottom security card.
