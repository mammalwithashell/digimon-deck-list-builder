## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=ST4-11 (via data/card_official_qa.json)_
- **Q652** (2024-03-28) Q: I use this card's inherited effect to trash an opponent's Security Card. Does the security effect on that card activate? — A: No, [Security] effects only activate when flipped over from the security stack.
- **Q653** (2024-03-28) Q: My opponent has an empty security stack. If I have a Digimon with this card in its digivolution cards, and I use it to attack and delete an opponent's Digimon and survive, do I win the game? — A: No, this effect only trashes the top card of your opponent's security stack. It doesn't win you the game if it's empty.
