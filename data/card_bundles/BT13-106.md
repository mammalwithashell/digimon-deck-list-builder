## Printed text (official)
### Effect
When an effect trashes this card from the security stack, activate this card's [Main] effect. [Main] 1 of your opponent's Digimon gets -3000 DP until the end of your opponent's turn. Then, if there're 6 or fewer total cards in both players' security stacks, all of your opponent's Digimon gain ＜Security Attack -1＞ until the end of your opponent's turn.

### Security Effect
[Security] Activate this card's [Main] effect.

## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT13-106 (via data/card_official_qa.json)_
- **Q2354** (2026-05-08) Q: Can I activate the "when an effect trashes this card from the security stack" effect when this card is revealed from the security stack or when searching/looking at this card from the security stack? — A: No, you can't. You can only activate the "when an effect trashes this card from the security stack" when this card is directly trashed from the security stack.
- **Q2355** (2026-05-08) Q: What does "if there're X or fewer total cards in both players' security stacks" mean, exactly? — A: It refers to when the total number of cards in both you and your opponent's security stacks is X or fewer. The text "if there're 6 or fewer total cards in both players' security stacks" would include when there're 3 cards in both players' security stacks, 2 cards in your security stack and 4 cards in your opponent's security stack, etc.
- **Q2356** (2026-05-08) Q: This card's effect caused the DP of my opponent's Digimon to become 0. At such times, is the Digimon with a DP of zero deleted? — A: No, it isn't deleted yet. Once all of the processing for the activated effect has resolved, a rule check will occur, then all of the Digimon with 0 DP are deleted at the same time.
