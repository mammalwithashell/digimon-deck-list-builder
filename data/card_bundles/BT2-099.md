## Printed text (official)
### Effect
Reduce the memory cost of this card in your hand by 1 for each yellow Tamer you have in play. [Main] 1 of your opponent's Digimon gets -12000 DP for the turn.


## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT2-099 (via data/card_official_qa.json)_
- **Q1501** (2024-03-28) Q: Can I use option cards that can change their cost to 7 on certain conditions such as [BT7-100 Qualialise Blast] or [BT11-108 DG Dimension] with this card’s [On Play] effect? — A: No, you can’t. Since those options are cards that have effects that “reduce the cost by…” or “its memory cost is equal to…” when they would be used, their cost has not actually changed when activating this card’s [On Play] effect, so they can’t be used with this card’s effect. However, since [BT2-099 Glorious Burst] always has the effect of reducing its use cost when used from the hand, if you have 2 yellow Tamers, it can be used with this card’s effect as its use cost will be 7. _(a ruling on BT6-112; this card is named in it)_

When such a card is used, does this card's "when you use an Option card with a use cost of 2 or more" effect trigger? — A: No, it doesn't trigger. If a card's cost itself is reduced when it's used from the hand, it's considered to be using an Option card with a use cost after the reduction is applied. Therefore, the "when you use an Option card with a use cost of 2 or more" effect doesn't trigger. _(a ruling on BT10-032; this card is named in it)_
