## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT26-082 (via data/card_official_qa.json)_
- **Q7117** (2026-08-18) Q: What is a {Security} effect? — A: A {Security} effect can be triggered/activated while its card is face up in the security stack. It can't be triggered or activated in areas other than the face-up security cards.
- **Q7118** (2026-08-18) Q: What happens to cards placed face up in the security stack by effects? — A: They become face-up security cards that remain revealed. Other than rules that specify face-up security cards, the rules apply in the same manner as standard security cards.
- **Q7119** (2026-08-18) Q: What happens upon a security check for a security card that is placed face-up? — A: The check is performed with the card left revealed. Other than rules for cards left revealed, the rules apply in the same manner as standard security checks.
- **Q7120** (2026-08-18) Q: Does a card's [Security] effect trigger upon a security check if that card is placed face-up? — A: Yes, it triggers.
- **Q7121** (2026-08-18) Q: What happens if I shuffle a security stack that includes security cards placed face-up? — A: Any face-up cards are placed face down, then you shuffle the cards. After shuffling, all cards are left face-down.
- **Q7122** (2026-08-18) Q: An opponent's Digimon attacks the player with an effect at the end of their turn. What happens if this card's {Security} [End of Opponent's Turn] effect then plays this card, my security stack is reduced to 0 cards, and the attack against the player is successful? — A: You lose the game.
- **Q7123** (2026-08-18) Q: Can I trash just 1 specified card for the conditions of this card's [When Digivolving] [End of Attack] effect? — A: No, you can't. A "by" condition can't be met if only some of the required actions are performed. The conditions for this [When Digivolving] [End of Attack] effect require you to trash the specified number of cards.
