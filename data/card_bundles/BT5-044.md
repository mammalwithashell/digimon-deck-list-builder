## Printed text (official)
### Effect
[Opponent's Turn] When an opponent's Digimon moves from the breeding area to the battle area, it gains ＜Security Attack -3＞ (This Digimon checks 3 fewer security cards) for the turn. [Your Turn] All of your opponent's Security Digimon get -3000 DP.

## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT5-044 (via data/card_official_qa.json)_
- **Q1328** (2024-03-28) Q: My opponent moves a Digimon from their breeding area to their battle area during the breeding phase. Does this card's [Opponent's Turn] effect activate? — A: Yes, it activates during the breeding phase.
- **Q1329** (2024-03-28) Q: During a security check, my opponent's Security Digimon has its DP reduced to 0 by this card's [Your Turn] effect. Is the Security Digimon deleted on the spot, without a battle? — A: No. Even if a Security Digimon is reduced to 0 DP, it still battles with the Digimon performing the security check.
- **Q1330** (2024-03-28) Q: This card's [Your Turn] effect reduces a Security Digimon's DP to 0, but it has a [Security] effect. What happens? — A: The [Security] effect activates normally.
- **Q1331** (2024-03-28) Q: A Security Digimon has its DP reduced by this card's [Your Turn] effect. If that Security Digimon is later played by its [Security] effect, does it still have its DP reduced when it enters play? — A: No. It's no longer a Security Digimon once it enters play, so it doesn't have its DP reduced by this card's effect.
