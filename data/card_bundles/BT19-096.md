## Printed text (official)
### Effect
[Main] You may place 1 Digimon card with the [Royal Base] trait from your trash face up as the bottom security card. Then, delete up to 8 play cost's total worth of your opponent's Digimon. For each of your face-up security cards, add 2 to this effect's play cost maximum.

### Security Effect
[Security] Activate this card's [Main] effects.

## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT19-096 (via data/card_official_qa.json)_
- **Q3171** (2024-11-22) Q: What happens to cards placed face up in the security stack by effects? — A: They become face-up security cards that remain revealed. Other than rules that specify face-up security cards, the rules apply in the same manner as standard security cards.
- **Q3172** (2024-11-22) Q: What happens upon a security check for a security card that is placed face-up? — A: The check is performed with the card left revealed. Other than rules for cards left revealed, the rules apply in the same manner as standard security checks.
- **Q3173** (2024-11-22) Q: Does a card's [Security] effect trigger upon a security check with that card placed face-up? — A: Yes, it triggers.
- **Q3174** (2024-11-22) Q: What happens if I shuffle a security stack that includes security cards placed face-up? — A: Any face-up cards are placed face down, then you shuffle the cards. After shuffling, all cards are left face-down.
