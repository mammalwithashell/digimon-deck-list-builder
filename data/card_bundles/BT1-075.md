## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT1-075 (via data/card_official_qa.json)_
- **Q925** (2024-03-28) Q: I attack with this card, and gain 3 memory from the card's attack effect. If this Digimon is deleted as a result of the attack, do I still lose 3 memory at end of turn? — A: Yes, the effect has already activated, so you lose 3 memory at end of turn.
- **Q926** (2024-03-28) Q: I attack with this card, and gain 3 memory from the card's attack effect. If I then announce that I'm passing, how much memory do I lose? — A: Announcing the pass moves the memory counter to 3 on your opponent's side. Since it's the end of the turn, you then lose an additional 3 memory, moving the memory counter to 6 on your opponent's side.
