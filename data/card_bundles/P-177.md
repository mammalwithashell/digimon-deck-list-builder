## Official Q&A
- No, you can't activate it. When a Digimon is deleted and an [On Deletion] effect on a digivolution card is triggered, it will only be pending activation for the Digimon card with that digivolution card. If a card with an effect that's pending activation leaves that area before the effect activates, the effect can no longer be activated. In this case, if BT21-068 [Growlmon] is deleted and an [On Deletion] effect on a digivolution card is triggered, the effect will only be pending activation for BT21-068 [Growlmon]. If the deleted BT21-068 [Growlmon] leaves the trash, the inherited [On Deletion] effect that was pending activation can no longer be activated. Related Cards
