## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=EX6-027 (via data/card_official_qa.json)_
- **Q3744** (2024-03-28) Q: Can I activate this card's [On Play] [When Digivolving] effect when I have 0 security cards? — A: No. If you can't add cards from your security stack to the hand, you can't activate the effect.
- **Q3745** (2024-03-28) Q: Can I use this Digimon to attack with this card's [All Turns] effect if it digivolved from a Digimon that was played this turn or a suspended Digimon? — A: No, you can't. This effect does not allow you to attack with this Digimon if it is in a state where it can't attack.
- **Q3746** (2024-03-28) Q: When a card is removed from my security stack, can I use this card's [All Turns] effect to gain <Security A. +1> without attacking? — A: No, you can't. You must gain <Security A. +1> and attack, or you must neither gain <Security A. +1> nor attack.
