## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT4-105 (via data/card_official_qa.json)_
- **Q1269** (2024-03-28) Q: I use this card's effect to place a Digimon on top of my security stack. Does that Digimon's [On Deletion] effect(s) activate? — A: It wasn't deleted, so [On Deletion] effects don't activate.
- **Q1270** (2024-03-28) Q: Can I use this card's effect to place my [EX2-007 Mother D-Reaper] on top of my security stack from the battle area? — A: No, you can't. If your [EX2-007 Mother D-Reaper] is chosen as the target to place in the security stack, according to the rules it will be placed at the bottom of the Digi-Egg deck instead of the security stack. A card isn't actually added to the security stack, therefore effects such as "when a card is added to the security stack" don't trigger. _(related: EX2-007)_
- **Q1271** (2024-03-28) Q: Can I use this card's effect to place my token that was played as a Digimon on top of my security stack from the battle area? — A: No, you can't. If your token is chosen as the target to place in the security stack, according to the rules it's removed from the game instead of being placed in the security stack. A card isn't actually added to the security stack, therefore effects such as "when a card is added to the security stack" don't trigger.
- **Q1272** (2024-03-28) Q: If I choose my [EX2-007 Mother D-Reaper] or token that is treated as a Digimon in the battle area as the target for this card's effect, it isn't placed in the security stack. In such cases, do "when a card is removed from the security stack" effects trigger because a card wasn't added to the security stack even though it normally should have been added? — A: No, they don’t trigger. _(related: EX2-007)_
- **Q1962** (2025-11-21) Q: I used this card's [When Digivolving] effect to use BT4-105 [Tactical Retreat!], then I placed this card itself on top of the security stack. At such times, after using BT4-105 [Tactical Retreat!], will it be placed in the security stack by the "place the Option card used with this effect on top of your security stack face down instead of placing it in your trash" effect? — A: Yes, it will be placed in the security stack. _(a ruling on BT10-041; this card is named in it)_
- **Q3284** (2024-03-28) Q: If I use [BT4-105 Tactical Retreat!] on this card, can I place it on top of my security stack face down? — A: No. This card is a Digi-Egg card, so if it would be moved to your security stack, it’s instead placed at the bottom of your Digi-Egg deck face down. _(a ruling on EX2-007; this card is named in it)_
