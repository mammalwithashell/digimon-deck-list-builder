## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT24-014 (via data/card_official_qa.json)_
- **Q5584** (2026-05-08) Q: This card's effect caused the DP of my opponent's Digimon to become 0. At such times, is the Digimon with a DP of zero deleted? — A: No, it isn't deleted yet. Once all of the processing for the activated effect has resolved, a rule check will occur, then all of the Digimon with 0 DP are deleted at the same time.
- **Q5585** (2025-12-25) Q: P-194 [Aegiomon] performs a security check, and when it would be deleted in battle against a Security Digimon, <Barrier> prevents the deletion. If I then use BT24-003 [Tsunomon] or BT24-084 [Inori Misono]'s effect to digivolve P-194 [Aegiomon] into this card, do I perform another security check using <Security A. +1>? — A: Yes, you perform an additional security check. _(related: P-194, BT24-003, BT24-084)_
