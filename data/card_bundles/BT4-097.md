## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT4-097 (via data/card_official_qa.json)_
- **Q1248** (2024-03-28) Q: When my opponent's Digimon attacks and checks my security, I activate this card's effect to gain 1 memory, moving the memory counter to 1 on my side. Does the attack end, even if my opponent's Digimon has checks remaining from <Security Attack +1>? — A: No, as long as there are attacks and effects that have triggered but haven't finished resolving yet, the attack continues regardless of the memory gauge's current position.
- **Q1249** (2024-03-28) Q: While this Tamer is in my battle area, my opponent's Digimon checks my security stack and flips over [BT1-107 Holy Wave]. Its [Security] effect activates, adding a card to my security stack. The number of cards in my security stack remained the same, but can I still suspend this card to gain 1 memory? — A: Yes, because a card was removed from your security stack. _(related: BT1-107)_
- **Q1250** (2024-03-28) Q: While this Tamer is in my battle area, I use [BT1-087 Matt Ishida]'s effect to add a yellow card from my security stack to my hand, triggering <Recovery +1 (Deck)> and adding a card to my security stack. The number of cards in my security stack remained the same, but can I still suspend this card to gain 1 memory? — A: Yes, because a card was removed from your security stack. _(related: BT1-087)_
- **Q1251** (2024-03-28) Q: If my opponent uses a card like [BT2-020 Gallantmon] to trash a card in my security directly, can I activate this card's effect? — A: Yes, you can. _(related: BT2-020)_
- **Q1252** (2024-03-28) Q: If I activate an effect like [BT4-104 Blinding Ray] to remove cards from my own security stack, can I activate this card's effect? — A: Yes, you can. _(related: BT4-104)_
- **Q1253** (2024-03-28) Q: If this card is played by its [Security] effect, can I suspend it to gain 1 memory? — A: "No, you can't. Since this card hasn't been played when it is revealed from your security, the condition for [When a card is removed from your security stack] can't be triggered, so this card's effect can't be activated."
- **Q2010** (2024-03-28) Q: My security cards were revealed due to the [When Digivolving] effect of this opponent's card, and 1 of them was trashed. Can I treat this as "when a card is removed from your security stack" and activate [BT4-097 Kari Kamiya]'s effect? — A: Yes, you can activate it. When a revealed card is trashed from the deck or security stack, it is not considered to be trashed from the deck or security stack, but it is considered that a card was removed from the security stack, so [BT4-097 Kari Kamiya]'s effect can be activated. _(a ruling on BT10-086; this card is named in it)_
