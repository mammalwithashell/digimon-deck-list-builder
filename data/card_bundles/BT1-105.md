## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT1-105 (via data/card_official_qa.json)_
- **Q972** (2024-03-28) Q: What does "original DP" refer to? — A: The DP value printed on a card is its original DP. This card's effect temporarily allows you to treat the DP value printed on an opponent's Digimon as if it were 3000.
- **Q973** (2024-03-28) Q: I use this card's effect to change the original DP of an opponent's Digimon to 3000. I then use [ST3-11 Seraphimon]'s effect to give an opponent's Digimon -4000 DP. If the opponent's Digimon drops to 0 DP, is it deleted? — A: Yes, when a Digimon's DP becomes 0, it's deleted. _(related: ST3-11)_
- **Q974** (2024-03-28) Q: This card's effect has set a Digimon's original DP to 3000. If [ST1-13 Shadow Wing] is used to give that Digimon +3000 DP, is its DP now 6000? — A: Yes, effects that increase or decrease DP work as normal, raising the Digimon's DP to 6000. _(related: ST1-13)_
- **Q975** (2024-03-28) Q: If I use this card's effect on a Digimon that's already getting +1000 DP from an effect, does its DP become 3000? — A: No, its original DP becomes 3000. 3000 DP and 1000 DP (from the effect) add up to 4000 DP.
- **Q976** (2024-03-28) Q: I digivolve a Digimon while this card's effect is active. What happens to the Digimon's DP? — A: Even after digivolving, the Digimon's DP is treated as 3000 until the end of the turn.
