## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT16-013 (via data/card_official_qa.json)_
- **Q2606** (2024-03-28) Q: Does this card’s [All Turns] effect activate when a security card is removed from my security stack by one of my own effects? — A: Yes, it activates.
- **Q2607** (2024-03-28) Q: After gaining <Security A. +1> from this card's [All Turns] effect during my opponent's turn, can this Digimon gain <Security A. +1> again from this card's [All Turns] effect during my next turn? — A: Yes, it can.
- **Q2608** (2024-03-28) Q: Can I activate this card's [All Turns] effect twice when I use one of my Digimon with <Security Attack +1> to check 2 cards in my opponent's security stack? — A: No, you can't. This effect is triggered "when a card is removed from your opponent's security stack," so even when you check multiple cards in your opponent's security stack, it is triggered and activates upon the first check. Also, this is a [Once Per Turn] effect, so this effect activates when a card is removed from their security stack upon the first check, and you can't activate the effect again upon the next check.
- **Q2609** (2024-03-28) Q: If the [All Turns] effect gives this Digimon <Security A. +1> when this card attacks and I check my opponent's security stack, do I get an additional security check? — A: Yes, you do.
- **Q2610** (2024-03-28) Q: An opponent's Digimon with <Security A. +1> and 8000 DP or less attacked and a security check occurred. If I use this card's [All Turns] effect to delete my opponent's attacking Digimon before the 2nd security check is performed, can I prevent the 2nd security check? — A: Yes, you can.
- **Q2611** (2024-03-28) Q: My Digimon attacked a player and a security check occurred. If this card leaves the battle area due to the revealed card's [Security] effect, does this card’s [All Turns] effect activate? — A: No, it doesn’t activate. The effect triggers when a card is removed from a security stack, but this card is removed from the battle area before it can activate.
