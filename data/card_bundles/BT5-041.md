## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT5-041 (via data/card_official_qa.json)_
- **Q1325** (2024-03-28) Q: I flip over an opponent's Security Digimon during a security check, and this card's inherited effect reduces its DP to 0. Is the Digimon deleted on the spot, without a battle? — A: No. Even if a Security Digimon is reduced to 0 DP, it still battles with the Digimon performing the security check.
- **Q1326** (2024-03-28) Q: This card's inherited effect reduces a Security Digimon's DP to 0, but it has a [Security] effect. What happens? — A: The [Security] effect activates normally.
- **Q1327** (2024-03-28) Q: A Security Digimon has its DP reduced by this card's inherited effect. If that Security Digimon is later played by its [Security] effect, does it still have its DP reduced when it enters play? — A: No. It's no longer a Security Digimon once it enters play, so it doesn't have its DP reduced by this card's effect.
