## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=EX5-063 (via data/card_official_qa.json)_
- **Q3666** (2025-06-13) Q: Can I process the part of the effect after "then" in this card's [On Play] [When Digivolving] effect even if the "if" condition in the 1st process isn't met? — A: Yes, you can process it. Even if your opponent doesn't have as many or more total Digimon and Tamers as you, this card's [On Play] [When Digivolving] effect will delete 1 of your opponent's lowest level Digimon.
- **Q3667** (2026-03-13) Q: I activated this card's [On Play] [When Digivolving] effect, and when my opponent's Digimon would leave the battle area for the 1st process, an immediate-type effect such as a "when [...] would leave" effect caused this card to be removed from the battle area. Can I then process the part of the effect after "then" in this card's effect? — A: Yes, you can. If an effect activates, it is to be fully resolved even if the card that activated the effect is removed from that area during the processing.
- **Q4735** (2025-06-13) Q: This card is placed in the battle area while EX5-063 [Leviamon] and BT15-081 [Leviamon (X Antibody)] are in the trash. When an opponent's Digimon is played by an effect, can I use this card's <Delay> effect to play EX5-063 [Leviamon], then digivolve that Digimon into BT15-081 [Leviamon (X Antibody)] using its own {Trash} [All Turns] effect? — A: Yes, you can. When the opponent's Digimon is played by an effect, this card's <Delay> effect and BT15-081 [Leviamon (X Antibody)]'s {Trash} [All Turns] effect will trigger simultaneously. You activate this card's <Delay> effect first and play EX5-063 [Leviamon] from the trash. EX5-063 [Leviamon]'s effect derived triggers, then BT15-081 [Leviamon (X Antibody)]'s triggered {Trash} [All Turns] effect can digivolve EX5-063 [Leviamon] into BT15-081 [Leviamon (X Antibody)]. _(a ruling on EX5-069; this card is named in it)_
- **Q6035** (2026-03-13) Q: I activated this card's [On Play] [When Digivolving] effect, and when my opponent's Digimon would leave the battle area for the 1st process, an immediate-type effect such as a "when [...] would leave" effect caused this card to be removed from the battle area. Can I then process the part of the effect after "then" in this card's effect? — A: Yes, you can. If an effect activates, it is to be fully resolved even if the card that activated the effect is removed from that area during the processing. However, you can't activate this card's [All Turns] effect.
- **Q6036** (2026-03-13) Q: When I use this card's [On Play] [When Digivolving] effect to delete my opponent's highest level Digimon, can I activate this card's [All Turns] effect and then activate the part of the [On Play] [When Digivolving] effect after "then"? — A: No, you can't. Once all of the processing is resolved for this card's [On Play] [When Digivolving] effect, then you can activate the [All Turns] effect for each deletion.
- **Q6037** (2026-03-13) Q: Does this card's [All Turns] effect give me 1 memory for each deletion if multiple opponent's Digimon are deleted at the same time in cases such as a "delete 2 of your opponent's Digimon" effect? — A: Yes, it does. You can reference the number of your opponent's Digimon for "gain 1 memory for each Digimon deleted" even when multiple Digimon are deleted. Even if multiple opponent's Digimon are deleted at the same time, this effect gives you 1 memory for each one deleted.
- **Q6038** (2026-03-13) Q: Does this card's [All Turns] effect give me 1 memory for each deletion if both my Digimon and my opponent's Digimon are deleted at the same time in cases such as a "delete 2 Digimon" effect? — A: You only gain 1 memory for each opponent's Digimon deleted. You can reference the number of your opponent's Digimon for "gain 1 memory for each Digimon deleted" even when multiple Digimon are deleted. However, you can't include any of your Digimon that are deleted at the same time.
- **Q6039** (2026-03-13) Q: I attempted to delete my opponent's EX10-052 [Lucemon] using this card's [On Play] [When Digivolving] effect. Then, the [All Turns] effect on my opponent's EX10-052 [Lucemon] activated, I deleted one of my Digimon other than this card, and EX10-052 [Lucemon] was deleted. If I then activate this card's [All Turns] effect, how much memory do I gain? — A: You gain 1 memory. _(related: EX10-052)_
