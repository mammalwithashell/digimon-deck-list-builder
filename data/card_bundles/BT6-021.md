## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT6-021 (via data/card_official_qa.json)_
- **Q1415** (2024-03-28) Q: My opponent has this Digimon in play. What happens if an effect is activated that causes you to gain memory on activation and lose memory at end of turn? (i.e. [BT1-090 Gravity Crush], [BT1-021 MetalGreymon], [BT1-040 WereGarurumon], [BT1-058 Chirinmon], [BT1-075 Digitamamon], etc.) — A: You can't use Option/Digimon card effects to gain memory, but you can still lose memory if a card effect specifies as such. At the end of the turn, you’ll lose memory as specified by each effect. _(related: BT1-090, BT1-040, BT1-058)_
- **Q1416** (2024-03-28) Q: My opponent has this Digimon in play. Can I gain memory from the security effect of [ST2-13 Hammer Spark]? — A: No, this Digimon prevents you from gaining memory from security effects. _(related: ST2-13)_
