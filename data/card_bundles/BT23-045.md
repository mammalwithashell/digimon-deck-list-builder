## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT23-045 (via data/card_official_qa.json)_
- **Q5307** (2025-10-03) Q: What happens to cards placed face up in the security stack by effects? — A: They become face-up security cards that remain revealed. Other than rules that specify face-up security cards, the rules apply in the same manner as standard security cards.
- **Q5308** (2025-10-03) Q: What happens upon a security check for a security card that is placed face-up? — A: The check is performed with the card left revealed. Other than rules for cards left revealed, the rules apply in the same manner as standard security checks.
- **Q5309** (2025-10-03) Q: Does a card's [Security] effect trigger upon a security check with that card placed face-up? — A: Yes, it triggers.
- **Q5310** (2025-10-03) Q: What happens if I shuffle a security stack that includes security cards placed face-up? — A: Any face-up cards are placed face down, then you shuffle the cards. After shuffling, all cards are left face-down.
- **Q5331** (2026-09-18) Q: I only have a face-up BT23-045 [TigerVespamon ACE] in my security stack. If I use this card's [When Attacking] effect to activate that BT23-045 [TigerVespamon ACE]'s [On Play] effect, can I choose to not process the [On Play] effect's "by" condition? — A: Yes, you can. An effect that activates another effect lets you decide whether or not to process that other effect's "by" conditions. _(a ruling on BT23-060; this card is named in it)_
