## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=EX11-063 (via data/card_official_qa.json)_
- **Q5922** (2026-02-06) Q: Can I use this card's [On Play] effect to place a card from my hand as a security card even if I have 0 cards in my security stack? — A: Yes, you can.
- **Q5923** (2026-02-06) Q: What happens to cards placed face up in the security stack by effects? — A: They become face-up security cards that remain revealed. Other than rules that specify face-up security cards, the rules apply in the same manner as standard security cards.
- **Q5924** (2026-02-06) Q: What happens upon a security check for a security card that is placed face-up? — A: The check is performed with the card left revealed. Other than rules for cards left revealed, the rules apply in the same manner as standard security checks.
- **Q5925** (2026-02-06) Q: Does a card's [Security] effect trigger upon a security check with that card placed face-up? — A: Yes, it triggers.
- **Q5926** (2026-02-06) Q: What happens if I shuffle a security stack that includes security cards placed face-up? — A: Any face-up cards are placed face down, then you shuffle the cards. After shuffling, all cards are left face-down.
- **Q5927** (2026-02-06) Q: Can I use this card's [End of Your Turn] effect to give <Collision> and <Piercing> to a Digimon, but then choose to not attack with that Digimon? — A: No, you can't. The Digimon that was given <Collision> and <Piercing> by this effect must attack if possible.
