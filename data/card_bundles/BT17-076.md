## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT17-076 (via data/card_official_qa.json)_
- **Q2844** (2024-11-22) Q: Does this card's [Your Turn] effect trigger when this card itself is played? — A: Yes, it triggers.
- **Q2845** (2025-07-04) Q: My BT6-083 [Eosmon] was played, then this card's [All Turns] effect and another effect triggered simultaneously. If another effect activates and the DP of my played BT6-083 [Eosmon] changes from 4000 to 5000, then I activate this card's [All Turns] effect, what is the DP of Digimon I can delete? — A: 5000 DP or less. If the same reference to a "played" trigger condition being performed isn't being made for an effect when it has a "when X is played" trigger condition, the state when the effect is processed will be referenced. In this case, processing was performed when your BT6-083 [Eosmon] had 5000 DP, therefore you can delete a Digimon with 5000 DP or less. _(related: BT6-083)_
- **Q2846** (2025-07-04) Q: Another of my [Eosmon] was played, then this card's [All Turns] effect and another effect triggered simultaneously. I activated the other effect, then my played [Eosmon] was removed from the battle area. If I then activate this card's [All Turns] effect, can I delete an opponent's Digimon? — A: No, you can't. If the same reference to a "played" trigger condition being performed isn't being made for an effect when it has a "when X is played" trigger condition, the state when the effect is processed will be referenced. In this case, because the Digimon that could be referenced by this card's [All Turns] effect was removed, you can't delete a Digimon.
