## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT25-079 (via data/card_official_qa.json)_
- **Q6380** (2026-05-08) Q: What does the "players can't gain memory other than by Tamer effects" effect do, exactly? — A: With this effect, players' memory will no longer increase by any effects except Tamer effects. This effect affects both players.
- **Q6381** (2026-05-08) Q: Can I gain memory using an effect on a Tamer that's treated as a Digimon with X000 DP due to an effect while my opponent has "players can't gain memory other than by Tamer effects" activated? — A: Yes, you can. When an effect is activated on a card that's treated as both a Digimon and a Tamer, the effect is treated as both a Digimon effect and a Tamer effect, therefore you can gain memory.
