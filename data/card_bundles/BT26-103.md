## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT26-103 (via data/card_official_qa.json)_
- **Q7187** (2026-08-18) Q: Can I activate a [Counter] effect and then activate another [Counter] effect? — A: No, you can't. Only 1 [Counter] effect can be activated during 1 attack.
- **Q7188** (2026-08-18) Q: I have 0 security cards. Can I activate this card's [When Digivolving] [Counter] effect and perform <Recovery +2> without trashing a security card? — A: Yes, you can.
- **Q7189** (2026-08-18) Q: When performing a security check, if a [Security] effect, a "when this Digimon checks an opponent's security" effect, and a "when a security stack is removed from" effect trigger simultaneously, what order do they activate in? — A: The [Security] effect is activated first. When a [Security] effect is checked, it is activated immediately without waiting. Activate the other triggered effects in order, starting with the turn player's effects.
