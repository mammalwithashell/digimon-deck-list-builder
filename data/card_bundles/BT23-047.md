## Official Q&A
_Source: https://world.digimoncard.com/rule/?card_no=BT23-047 (via data/card_official_qa.json)_
- **Q5313** (2025-10-03) Q: What order do a [Security] effect, "when [...] performs a security check" effect, and "when a card is removed from [...] security stack" effect activate when they trigger simultaneously upon a security check? — A: [Security] effects take precedence for activation. Upon a security check, a [Security] effect will immediately activate without pending activation. For other triggered effects, the turn player activates their effects first.
- **Q5314** (2025-10-03) Q: What does the "trash 1 Option card in your opponent's battle area" effect do, exactly? — A: This effect trashes an Option card that was placed by a "place this card in the battle area" effect.
- **Q5315** (2025-10-03) Q: When this card is used to check my opponent's security stack, P-035 [Red Memory Boost!] is checked, and its [Security] effect places that card in the battle area. Can I then use this card's [Your Turn] effect to trash the P-035 [Red Memory Boost!] that was placed in the battle area? — A: Yes, you can. If this card is used to check your opponent's security stack and P-035 [Red Memory Boost!] is revealed, this card's [Your Turn] effect will trigger at the same time. The [Security] effect will activate first, therefore P-035 [Red Memory Boost!]'s [Security] effect places that card in the battle area. You can then use the [Your Turn] effect that's pending activation on this card to trash that P-035 [Red Memory Boost!]. _(related: P-035)_
