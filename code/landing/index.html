system capabilities

Faithful rules engine
Card effects implement the printed text — every choice a card offers is a real choice, no shortcuts. Built in Rust.
AI opponents
Agents trained with reinforcement learning over millions of games. Models download on demand and run locally.
Deck builder
Build and validate decks against the tested card pool. Import lists, save locally, jump straight into a game.
Room-code PvP
Share a code, play a friend over the hosted server. No account dance — make a name, send the code.
Offline play
Games against AI run entirely on your machine. The network is only needed for PvP and model downloads.
Auto-updates
Signed updates on the alpha channel. Install once; the app keeps itself current.

field manual

Windows: the installer is not yet code-signed, so SmartScreen will object. Click More info → Run anyway. That warning is expected for the alpha.
Linux: make the AppImage executable before first launch: chmod +x digimon-tcg-*.AppImage
Bugs: it is an alpha of a very large rules engine — when something misbehaves, file an issue with the card(s) involved and what you expected.
