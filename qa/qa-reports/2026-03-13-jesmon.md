## Critical Bugs Found

### BUG-1: BT23-013 Jesmon - Unfiltered play_filter allows ANY card
**Severity**: HIGH
**File**: `digimon_gym/engine/data/scripts/bt23/bt23_013.py`
**Issue**: Lines 101-104 and 135-138 - `play_filter` returns `True` for all cards instead of filtering for cards with [Sistermon] in their name. The When Digivolving and When Attacking effects allow playing ANY card from hand/trash for free.
**Expected**: Filter for `c.contains_card_name('Sistermon')` or Atho/Rene/Por tokens only.
**Confirmed via gameplay**: Selection offered Gankoomon, Jesmon GX, Huckmon alongside Sistermon Blanc.

### BUG-2: BT23-013 Jesmon - Token play not implemented
**Severity**: MEDIUM
**File**: `digimon_gym/engine/data/scripts/bt23/bt23_013.py`
**Issue**: Lines 106 and 140 - "Play AthoRenePor Token" is stubbed with `pass # descriptive-tagged: play_token`

### BUG-3: BT23-013 Jesmon - Force attack not implemented
**Severity**: MEDIUM
**File**: `digimon_gym/engine/data/scripts/bt23/bt23_013.py`
**Issue**: Line 172 - "[Your Turn] [Once Per Turn] When any of your other Digimon are played, this Digimon may attack" is stubbed.

### BUG-4: BT22-046 Gargomon - Unfiltered play_filter
**Severity**: HIGH
**File**: `digimon_gym/engine/data/scripts/bt22/bt22_046.py`
**Issue**: Lines 58-59 - `play_filter` returns `True` instead of filtering for Tamer cards with [CS] trait. Also missing check for "1 or fewer Tamers" condition.

### BUG-5: ST1-07 Greymon - Causes server hang
**Severity**: CRITICAL
**File**: `digimon_gym/engine/data/scripts/st1/st1_07.py`
**Issue**: Playing this card causes the server to hang indefinitely. The script defines an inherited effect with no timing and `condition` always returns True, which may cause an infinite loop in the engine's effect processing.

### BUG-6: BT23-044 Lilamon - Suspends opponent's Digimon instead of own
**Severity**: HIGH
**File**: `digimon_gym/engine/data/scripts/bt23/bt23_044.py`
**Issue**: Lines 113-114 use `game.effect_select_opponent_permanent` but the card text says "By suspending 1 Digimon" (your own, as a cost). Should be `game.effect_select_own_permanent`.

### BUG-7: BT20-013 BaoHuckmon - Free play instead of cost-reduced
**Severity**: MEDIUM
**File**: `digimon_gym/engine/data/scripts/bt20/bt20_013.py`
**Issue**: Lines 46-47 use `free=True` for `effect_play_from_zone`, but the card says "with the play cost reduced by 2" (not free). The `cost_reduction = 2` property is set but ignored because `free=True` bypasses cost entirely.

### BUG-8: ST12-15 From Master to Disciple - Incorrect trash/hand handling
**Severity**: MEDIUM
**File**: `digimon_gym/engine/data/scripts/st12/st12_15.py`
**Issue**: Lines 37-39 incorrectly add a random card from trash to hand before the reveal. Lines 49 put remaining revealed cards to library bottom instead of trashing them. The Delay effect process is stubbed.

## Engine-Level Issues Noted

1. **Token play not supported**: Multiple Jesmon cards reference [Atho, Rene & Por] tokens but token generation is not implemented in the engine.
2. **Force attack not implemented**: Several cards have "this Digimon may attack" triggers that are stubbed.
3. **grant_skill not implemented**: Granting keywords (like Piercing) to other Digimon is stubbed in multiple scripts.
4. **Mandatory permanent selection with no targets**: Some scripts use `is_optional=False` for permanent selection effects. If no valid targets exist, this may cause the engine to hang.

## Test Methodology

- Created debug games via `POST /debug/games` with `skip_shuffle=true` and specified starting hands
- Injected test cards via `POST /debug/games/{id}/inject-card`
- Executed actions via `POST /games/{id}/actions` with specific action IDs
- Verified state changes via `GET /debug/games/{id}/internal-state`
- For high-cost cards (>10 memory), conducted script review instead of live play
- All scripts at `digimon_gym/engine/data/scripts/{set_id}/{card_id}.py` were verified to exist and compile
