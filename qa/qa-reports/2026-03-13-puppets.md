## Issues Found (32 total)

### Critical: Missing/Broken Effect Implementations

1. **EX11-024 Cendrillmon (L6)** - All 4 timing-based effects have NO process callbacks and use generic "Effect" descriptions. Alliance and Overclock declarative effects work, but On Play/When Digivolving (play L4 Puppet + tokens + -3000 DP per Digimon) and When Attacking (-3000 per Digimon) are completely unimplemented.

2. **EX11-022 Karakurumon (L5)** - On Play/When Digivolving effect is completely wrong. Card text says "play Puppet with 4000 DP or less from hand/trash free, delete at turn end." Script instead tries to delete an opponent's Digimon then play any Digimon, then grants effect immunity. The WhenRemoveField inherited effect (delete Puppet to prevent leaving) also has no process callback.

3. **EX9-067 Mirai Kinosaki (Tamer)** - [Your Turn] digivolve trigger uses wrong timing mechanism. Sets `is_when_digivolving = True` on `OnEnterFieldAnyone` timing, but the engine only fires WhenDigivolving on the permanent that actually digivolved (`perm is digivolved_perm`). Since this is a Tamer, it will never fire. On Play reveal effect works correctly.

4. **EX9-033 Kaguyamon (L6)** - Blocker/Alliance grant effects have wrong condition. The condition checks if the card's OWN permanent is a Puppet/Token, instead of checking ALL friendly Puppet/Token permanents. This means the keyword grants only apply to itself, not to all Puppet Digimon as card text specifies. The OnDestroyedAnyone and OnEndTurn effects have process callbacks and appear correct.

5. **EX11-060 Arisa Kinosaki (Tamer)** - On deletion trigger is wrong: (a) doesn't check if deleted card is Token/Puppet, (b) process suspends opponent's permanent instead of suspending itself, (c) Overclock detection completely missing, (d) play filter doesn't check Puppet trait. Start-of-turn memory set works correctly.

6. **P-156 Future Potential! (Option)** - Main effect doesn't choose a Tamer for color matching (just plays any Digimon cost <=3). Security effect filter checks `is_digimon` instead of `is_tamer`. "Add to hand" implementation pops from trash generically instead of adding the specific option card.

### High: Stub/Unimplemented Effects

The `effect_play_token(player, 'familiar')` API exists and works (ST19-12 uses it), but BT22-040 wasn't updated. The [All Turns] deletion trigger (re-activate When Digivolving) also has no process callback.

8. **EX11-019 Shoemon (L3)** - On Deletion Familiar Token play is stubbed. Same stub issue as above.

9. **P-165 ShoeShoemon (L4)** - Both On Play and When Digivolving Familiar Token plays are stubbed. Security play effect is present.

10. **P-134 Shoemon (L3)** - On Play SA-1 grant to opponent's Digimon is stubbed (`pass # descriptive-tagged: change_security_attack`).

11. **BT22-042 Nyabootmon (L7)** - When Digivolving effect (play L4 Puppet + -3000 DP per Digimon) has process callback and works. BUT the [All Turns] deletion trigger (re-activate When Digivolving) has no process callback.

12. **BT22-036 Chaperomon (L5)** - The inherited WhenRemoveField effect (delete Puppet to prevent leaving) has no process callback. Overclock and Hand-digivolve effects appear correct.

### Medium: Missing Inherited/Triggered Effects

### Engine Notes

- Token infrastructure works: `game.effect_play_token(player, 'familiar')` correctly creates Familiar Tokens with On Deletion -3000 DP
- Overclock is a keyword attribute (`_is_overclock = True`) handled by the engine; correctly requires another Puppet/Token to sacrifice
- Alliance is declarative (`_is_alliance = True`)
- Scapegoat is declarative (`_is_scapegoat = True`)
- WhenRemoveField timing requires process callbacks for "delete other to prevent leaving" effects
- The engine's `_effect_matches_timing` for `WhenDigivolving` only fires on the digivolved permanent itself -- Tamers/other permanents that listen for "when any of your Digimon digivolve" need a different approach (global event listener or OnEnterFieldAnyone with custom context checks)
