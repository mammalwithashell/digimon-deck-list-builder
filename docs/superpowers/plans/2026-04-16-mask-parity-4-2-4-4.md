## Task 1: §4.2 Option card color requirement

**Context:** Python's `build_action_mask` ([action_mask.py:77-99](../../../digimon_gym/engine/game/action_mask.py#L77)) requires a player to have a Digimon *or* Tamer of a matching color on the field (or in breeding) before an Option card's play bit is set. Rust's mask ([mask.rs:53-64](../../../digimon-engine/src/action/mask.rs#L53)) has a TODO comment and skips this check. After this task, Rust honors the color requirement for **all** Option cards.

**Out of scope (documented in doc update as §4.2b):**
- Cards whose scripts set `card._match_color_requirement = False` or `_match_color_requirement_fn` (~10 cards). These currently have no equivalent in Rust (`CardData` has no such field). Rust will be *stricter* than Python for these — the Option is masked out even when Python would allow it. Fix requires card scripting infra (§4.5).
- `IGNORE_COLOR_REQUIREMENT` aura modifier. No such `ModifierType` variant in Rust yet, and no card in Rust's current pool emits it. Defer until a card needs it.

**Files:**
- Modify: `digimon-engine/src/action/mask.rs` (the Play-cards branch, lines ~53-64)
- Create: `digimon-engine/tests/mask_main_parity.rs`

```rust
/// Returns true if the player has any Digimon or Tamer on the battle area
/// (or a Digimon in breeding) whose color set intersects the Option's
/// color set. Mirrors Python's `action_mask.py` color-requirement check.
fn option_color_match_available(
    option: &crate::card_source::CardSource,
    me: &crate::player::Player,
    card_data: &[CardData],
) -> bool {
    let opt_colors: &[CardColor] = option.colors(card_data);
    if opt_colors.is_empty() {
        // Colorless Options have no requirement — Python never reaches the
        // intersection check on an empty list (it would always be empty).
        // Safe default: allow. This is consistent with BT/EX cards where
        // "no colors" means "no color tag", not "impossible to satisfy".
        return true;
    }
    for perm in &me.battle_area {
        if !(perm.is_digimon(card_data) || perm.is_tamer(card_data)) {
            continue;
        }
        let perm_colors = perm.top_card().colors(card_data);
        if perm_colors.iter().any(|c| opt_colors.contains(c)) {
            return true;
        }
    }
    if let Some(breed) = &me.breeding_area {
        if breed.is_digimon(card_data) {
            let breed_colors = breed.top_card().colors(card_data);
            if breed_colors.iter().any(|c| opt_colors.contains(c)) {
                return true;
            }
        }
    }
    false
}
```

```rust
    // when memory < 0. Python's action_mask.py:107-114 contract.
    let mut r = DebugRunner::builder()
        .add_card(fighter("ATK", CardColor::Red, 5000))
        .add_card(fighter("DEF", CardColor::Red, 3000))

    let attacker = r.place_on_field(tp, "ATK", Some(0));
    r.place_on_field(opp, "DEF", Some(0));

    // Simulate "digivolved this turn" and suspend a target so it's attackable.
    r.game.players[tp as usize].battle_area[attacker.index as usize]
        .turn_digivolved = r.game.turn_count;
    r.game.players[opp as usize].battle_area[0].is_suspended = true;

    r.game.enter_main_phase();
    r.game.set_memory(-3); // opponent's side of seesaw

    // Baseline: no Blitz → no attack bit.
    let mask_no_blitz = build_action_mask(&r.game, tp);
```

## Task 3: §4.4 Raid + CAN_ATTACK_UNSUSPENDED target rules

**Context:** Python ([action_mask.py:121-140](../../../digimon_gym/engine/game/action_mask.py#L121)) emits attack bits against unsuspended enemies under two conditions: (a) attacker has `CAN_ATTACK_UNSUSPENDED` modifier (or `_is_can_attack_unsuspended` keyword — no Rust equivalent), in which case *every* unsuspended enemy Digimon is a valid target; (b) attacker has Raid keyword, in which case only unsuspended enemies tied for highest DP are valid. Rust's mask ([mask.rs:83-89](../../../digimon-engine/src/action/mask.rs#L83)) filters targets to `target.is_suspended` only.

**Scope:** Both the Raid keyword (`Keyword::Raid`) and the `CanAttackUnsuspended` modifier variant already exist in Rust's enums. Use `Game::effective_dp(handle)` for the DP tiebreak so ChangeDp modifiers are honored (same function the combat resolver uses). Native static-keyword Raid follows §4.3b / §4.5 infra.

**Files:**
- Modify: `digimon-engine/src/action/mask.rs` (the target-emission inner loop from Task 2)
- Modify: `digimon-engine/tests/mask_main_parity.rs` (append)

```rust
fn mask_raid_targets_highest_dp_unsuspended() {

    let mut r = DebugRunner::builder()
        .add_card(fighter("ATK", CardColor::Red, 5000))
        .add_card(fighter("WEAK", CardColor::Blue, 2000))
```
