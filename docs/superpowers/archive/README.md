# Superpowers Archive

This folder keeps completed or stale Superpowers specs and plans out of the active working queues.

Archive criteria used on 2026-05-02:

- Files dated before 2026-04-25 were archived as older than one week.
- Newer files were archived only when recent commits or checked plan state showed the work had landed.
- Partially handled or current work stayed in `docs/superpowers/plans/` and `docs/superpowers/specs/`.

Keep original filenames when archiving so date and topic ordering remain stable.
