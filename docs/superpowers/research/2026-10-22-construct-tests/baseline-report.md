## 6. Caveats

- Token presence is a proxy for `tested`: a test that names `CompiledStep::Draw` in a fixture it never asserts on still counts; a construct exercised only through a cross-file helper (`support.rs`, `include_str!` of a card YAML) does NOT count. Attribution is per test + same-file helper closure by name (transitive, order-independent), so a helper whose name collides with a method call can over-attribute.
- `tested` (the brief's criterion) includes parse-only evidence. `tested_behaviourally` requires a hit in a test that itself runs the engine (an `ENGINE_RUN_MARKERS` match in its body or a same-file test-support helper, decided per test); the rest are `parsed_only` (parsed, not behaviourally tested).
